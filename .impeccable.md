# Design context — lynxtron-examples

## Target audience

Developers who already know Electron and are evaluating or learning Lynxtron.
They arrive from `electron/docs/fiddles` or the Lynxtron docs, and they read
these showcases the way you read an API reference: to find out whether a
specific capability exists and what calling it looks like.

They are not end users. Nobody is here to be delighted; they are here to find
out if `dialog.showOpenDialog` works.

## Use cases

- Open one showcase, see one API do one thing, and believe the result.
- Compare a Lynxtron call against the Electron call it replaces.
- Find out, without ambiguity, when a capability is **missing** rather than
  merely unimplemented here.

## Brand personality / tone

Restrained developer tooling. The established look is "Fiddle Dark" — the
palette in `packages/config/tokens.css`, exemplified by `showcases/counter`
(one number, two buttons, nothing else) and `showcases/system-monitor`
(labelled panels, monospace data).

- Utilitarian, not decorative. A showcase is evidence, not a landing page.
- Quiet by default; colour carries meaning (`--accent` for the primary action,
  `--ok` / `--error` for outcomes) and nothing else.
- **`--font-mono` is strictly for DATA** — numbers, paths, versions, timestamps,
  API identifiers. Never as shorthand for "technical vibes".
- Short. If a sentence does not change what the reader does next, delete it.

## Constraints

- **Lynx is not a browser.** `<view>` / `<text>` / `<image>` only; `bindtap`,
  not `onClick`. No DOM, no `window`.
- CSS is a subset: no `inline-flex`, no `:first-child` / `:nth-child`, no
  `min()` / `max()`. `:hover` is a Lynxtron extension — keep it colour-only,
  because `:hover` layout flips leave paint ghosts.
- Fully transparent views are skipped by hit-testing — tappable-but-invisible
  surfaces need `--hit-fill`.
- `packages/config/tokens.css` is the single source of palette truth. Import it;
  do not restate hex values.

## Differentiation

Honesty is the distinguishing feature. Every showcase states plainly what it
does, and the ported Electron fiddles say out loud when Lynxtron cannot do
something and what was substituted. That candour — not visual flourish — is what
these pages are for.
